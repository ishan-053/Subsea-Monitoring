# Subsea Pipeline Digital Twin

A Streamlit-based digital twin for monitoring subsea pipeline telemetry, detecting pressure transients, localizing potential leaks using Negative Pressure Wave (NPW) analysis, and simulating automated emergency isolation.

## Features

- Live telemetry replay
- Pressure anomaly detection
- Negative Pressure Wave (NPW) leak localization
- Automatic affected-segment identification
- Pipeline health monitoring
- Virtual emergency isolation
- Interactive 3D pipeline visualization
- Time Machine for telemetry replay
- Automatic incident reports
- Excel dataset upload
- No-leak scenario validation

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- OpenPyXL
